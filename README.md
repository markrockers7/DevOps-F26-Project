# DevOps-F26-Project
This Project will be a Grade Calculator to help with determining a user's grade in their classes and overall GPA. The purpose of this system is to give an easier, cleaner, and more efficient way to input grades. It also will view averages in sections of a class as well as the overall grade for that class. This system will support teachers inputting grades rather than using an excel sheet to make it easier for them to visualize and edit them. Many other tools that I have tried to use tend to give a current grade rather than seeing how much a grade will affect you at the end of a class. I have also heard that other professors tend to use excel sheets to store grades rather than utilizing other tools given to them by the university. So my plan is to make a program that can be useful for students and faculty alike.
